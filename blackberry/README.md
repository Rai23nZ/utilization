# Утилизация КНТ — BlackBerry 10

Нативное приложение для BlackBerry Passport (BlackBerry OS 10.3) на Cascades (QML + C++).
Android Runtime не используется. Логика та же, что в PWA из корня репозитория: сверка
результата проверки с актом списания, таймер, отметки, итог и выгрузка `.xlsx`.

Готовый пакет: [`dist/UtilizationKNT-1.0.2.bar`](dist/UtilizationKNT-1.0.2.bar). Он собран
в режиме разработчика и не подписан.

## Файлы и SD-карта

- **Входные файлы** выбираются на SD-карте (`/accounts/1000/removable/sdcard`). Список
  показывает папки и таблицы `.xlsx`, `.xlsm`, `.xls`, `.csv`, `.txt`.
- Поддерживаемые форматы:
  - `.xlsx`/`.xlsm`;
  - старый `.xls`: Excel 97–2003 (BIFF8) и Excel 5/95 (BIFF5);
  - «`.xls`», сохранённый как XML 2003 или HTML-таблица;
  - CSV в UTF-8 или Windows-1251 с разделителем `;`, `,` или табуляцией.
- **Папка `utilization`** создаётся на карте при первом запуске. В неё пишутся:
  - `Утилизация_КНТ_ДД_ММ_ГГГГ_ЧЧММ.xlsx` — листы «Утилизация» и «Итог», как в PWA;
  - `Итог_КНТ_….txt` — итог текстом, заодно копируется в буфер обмена;
  - `Лишние_КНТ_….txt` — список лишних номеров, если акт заблокирован;
  - `.session.json` и `.session-items.json` — автосохранение сессии. Сессия переживает
    перезапуск и даже переустановку `.bar`.

## Экраны

Стиль «пульт»: чёрный фон, янтарные клавиши, моноширинный IBM Plex.

1. **Загрузка.** Две большие плитки: «1 · Результат проверки» и «2 · Акт списания». Касание
   плитки открывает список файлов на карте. Ниже — сверка (к утилизации, в акте, не допущено,
   пустое решение) и клавиша «Начать утилизацию». Если есть незавершённая сессия, экран
   предложит продолжить её.
2. **Работа остановлена.** Появляется, если в акте есть лишние КНТ. Список можно скопировать
   (он же сохраняется в `.txt`) или сразу загрузить другой акт.
3. **Утилизация.**
   - Вверху — состояние таймера, время и счётчик. Под ними 30 сегментов прогресса.
   - На табло — номер КНТ (набранные цифры подсвечены), наименование, код товара, марка,
     цена и строка состояния.
   - Пульт: цифры 0–9 и ⌫ (долгое нажатие — очистить), «К неотм.», «Старт/Пауза/Продолжить»,
     «Сетка», «Подробно», «Завершить».
   - Большая клавиша «Утилизирован» (для отмеченной позиции — «Снять отметку»).
   - Карточка открывается сама на 4-й цифре.
   - Клавиатура Passport: цифры, Backspace, Enter — искать, Пробел — отметить.
4. **Сетка.** Все позиции плитками по 4 последним цифрам, в порядке наименований.
   - Утилизированные залиты синим и по умолчанию скрыты. Клавиша «Показать утил./Скрыть утил.»
     переключает их.
   - Касание плитки выдвигает снизу шторку с карточкой. В ней можно отметить утилизацию или
     снять отметку. После отметки шторка сама закрывается.
   - Таймер можно запустить и поставить на паузу прямо отсюда.
5. **Итог.** Чек процесса с неотмеченными позициями и журналом снятых отметок. Клавиши:
   «Выгрузить .xlsx», «Текст .txt» и «Заново».

Когда приложение свёрнуто, Active Frame показывает таймер и прогресс. Пока идёт таймер, экран
не гаснет. Отметка и ошибки ввода сопровождаются короткой вибрацией.

## Установка

Пакет собран с `-devMode`, как требует упаковщик для неподписанных приложений. Установите его
своим обычным способом установки неподписанных `.bar`. Приложению нужно разрешение
«Общие файлы» (`access_shared`) — без него нет доступа к SD-карте.

## Сборка

Сборка идёт на Linux. Инструменты BlackBerry 10 Native SDK 10.3.1 сохранились только для
Windows, поэтому компилятор `qcc` и `moc` запускаются через Wine, а упаковщик — на Java.

1. Скачайте с archive.org (коллекция `bbdevtools`) и распакуйте в один каталог:
   - `bbndk.win32.tools.10.3.1.12.zip`;
   - `bbndk.win32.libraries.10.3.1.995.zip`.
2. Поставьте Wine с 32-битной частью (`wine32:i386`) и Java 17+.
3. Соберите пакет:

   ```bash
   BBNDK=/путь/к/sdk ./build.sh      # → dist/UtilizationKNT-<версия>.bar
   ./build.sh host-test              # тесты ядра на хосте (Qt5 + zlib, Python: openpyxl, xlwt, LibreOffice)
   ```

`build.sh` перед сборкой запускает `tools/check_qml.py`. Скрипт сверяет каждый QML-файл с
описаниями типов Cascades из NDK (`plugins.qmltypes`): типы, свойства, сигналы, перечисления,
методы, обращения к контроллеру и палитре.

## Устройство кода

```
src/Book.hpp, BookRead.cpp   чтение таблиц: общие функции, CSV, XML 2003, HTML
src/XlsxRead.cpp, Zip.cpp    .xlsx (zip + XML), общие строки, форматы дат
src/XlsRead.cpp              .xls: контейнер OLE2 + записи BIFF8/BIFF5 (SST с CONTINUE, RK, MULRK, формулы)
src/XlsxWriter.cpp           запись .xlsx (два листа, inlineStr)
src/Logic.cpp                логика из app.js: шапка, «допущен», сверка, поиск, сортировка
src/Controller.cpp           состояние, таймер, отметки, сетка, сессия, выгрузка (в QML — app)
src/Platform.cpp             SD-карта, вибрация, буфер обмена, экран, JSON
assets/*.qml                 интерфейс; шрифты IBM Plex (OFL) и иконки
tests/                       тестовые книги и проверки ядра на хосте
tools/                       проверка QML, иконки, упаковщик
```
