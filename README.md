# Утилизация КНТ — PWA

Интерфейс для утилизации некондиционного товара: карточка КНТ, поиск по номеру,
таймер процесса и сверка с актом списания. Статический сайт, разворачивается на
GitHub Pages, ставится на Android как обычное приложение и работает без сети.

Форма взята из макета `КНТ_варианты_интерфейса.html` — вариант **В3 «Карточка товара»**.

## Как работает

1. **Загрузка двух файлов.**
   - *Результат проверки* — Excel со столбцами `Решение` и `№ КНТ`. В работу берутся
     только строки, где в «Решении» стоит ДОПУЩЕН. Пустое решение считается недопущенным
     и отдельно показывается в сводке.
   - *Акт списания* — Excel или CSV со столбцом `№ КНТ`. Шапка ищется в первых 30 строках,
     поэтому заголовок акта над таблицей не мешает.

2. **Сверка.**
   - Если в акте есть КНТ, которого нет среди допущенных, работа останавливается:
     показывается список лишних номеров с причиной (`НЕ ДОПУЩЕН` или `нет в списке проверки`)
     и кнопка «Копировать список» — готовый текст для отправки.
   - Если акт короче списка допущенных, но целиком в него входит, выборка сужается до акта.

3. **Утилизация.** Таймер (начать / пауза / продолжить / завершить), прогресс-бар
   `41 / 67 · осталось 26`, поле ввода номера. При вводе 4-й цифры карточка открывается сама;
   если под номер подходит несколько позиций, появляется список выбора. Отметка ставится
   одной кнопкой `УТИЛИЗИРОВАН` и только при запущенном таймере. Уже отмеченная позиция
   получает диагональный штамп, повторно отметить её нельзя — можно только снять отметку
   через подтверждение (снятия пишутся в журнал и попадают в отчёт).
   Товар отсортирован **только по наименованию**.

4. **Итог.** Сводка (утилизировано / осталось / чистое время / пауз), список неотмеченных
   позиций с копированием и выгрузка `.xlsx` с двумя листами: «Утилизация» (исходные столбцы
   + `Утилизирован` + `Время отметки`) и «Итог».

Прогресс сохраняется в браузере: вкладку можно закрыть или уронить — при следующем открытии
приложение предложит продолжить.

## Файлы

```
index.html                    разметка четырёх экранов
app.css                       стили (палитра макета)
app.js                        вся логика
vendor/xlsx.full.min.js       SheetJS — чтение xlsx/xls/csv и запись xlsx
manifest.webmanifest          манифест PWA
sw.js                         service worker, офлайн-кэш
icons/                        иконки 192/512/maskable
КНТ_варианты_интерфейса.html  исходный макет, оставлен для справки
```

### Библиотека SheetJS

Файл `vendor/xlsx.full.min.js` в репозитории обязателен — без него приложение скажет,
что не может читать Excel. Взять его можно так:

```bash
curl -L -o vendor/xlsx.full.min.js https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js
```

## Локальный запуск

Service worker и буфер обмена работают только по http(s), поэтому открывать файл
двойным щелчком (`file://`) не надо — поднимите локальный сервер:

```bash
python -m http.server 8080
```

Дальше `http://localhost:8080/`.

## Развёртывание на GitHub Pages

```bash
git init
git add .
git commit -m "Утилизация КНТ — PWA"
git branch -M main
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Затем в настройках репозитория: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

На Android: открыть этот адрес в Chrome → меню → «Установить приложение».
После установки приложение открывается с рабочего стола и работает без сети.

Service worker работает по схеме stale-while-revalidate: приложение открывается из кэша
мгновенно и без сети, а новая версия подтягивается фоном и применяется при следующем запуске.
Если нужно сбросить кэш принудительно (например, поменялся состав файлов) — поднимите номер
в `sw.js`: `const CACHE = 'utilization-knt-v2'`.

Аварийный выключатель кэша: открыть адрес с `?nosw` (например
`https://<логин>.github.io/<репозиторий>/?nosw`) — страница загрузится в обход service worker'а.
Пригодится при отладке и если в кэш попала сломанная версия.

## Приватность

Файлы читаются целиком в браузере, никуда не отправляются и нигде не сохраняются,
кроме локального хранилища этого устройства.
